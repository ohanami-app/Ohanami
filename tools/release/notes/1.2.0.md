ゲームのスクリーンショットを、セリフ・場面の文脈・見た目で探せる、Windows 向けのアプリです。外部のサービスは使わず、画像・検索語・インデックスは全てローカルの PC の中に置きます。

Ohanami is a local-only screenshot search app for Windows, made for game screenshots. Everything stays on your PC.

**この版で変わったこと / What's new**

- 短い日本語の単語で探したときに、検索語に関係なく、いつも同じ画像が上位に出てくることが減りました。特徴ベクトル検索の点から、「どの言葉にも近い画像」の分を引きます。開発者の手元の約 1,000 枚と 39 の検索語で測ると、上位 10 件の当たりが 185 件から 221 件に増えました。英語や長い文で探したときの結果は、今までと同じです。
- この補正をかけた検索では、「類似度」の数字が前より小さくなります。補正の分を引いた値です。
- Short Japanese queries no longer keep returning the same few images near the top. The visual search score now subtracts how close each image is to words in general. On the developer's ~1,000 screenshots and 39 queries, correct hits in the top 10 rose from 185 to 221. English queries and long sentences give the same results as before.
- For these queries, the "類似度" (similarity) value is smaller than before, because the correction is subtracted.

**1.1.0 以前からの更新 / Updating from 1.1.0 or earlier**

新しい zip を別の場所に展開して、古いアプリのフォルダを消します。データ(インデックス・手動タグ・モデルのファイル)は `%LOCALAPPDATA%\Ohanami` にあるので、そのまま引き継がれます。インデックスの作り直しも、モデルの取り直しも要りません。
Unzip the new version to a new folder and delete the old one. Your data (index, tags and model files) is in `%LOCALAPPDATA%\Ohanami` and is kept. You do not need to rebuild the index or download the models again.

**要るもの / Requirements**

- Windows 11(64 ビット)
- NVIDIA の GPU(Turing 以降、VRAM 8GB 以上)、メモリ 16GB 以上
- ディスクの空き: アプリの展開後が約 1.6GB、モデルが約 10.8GB

**入れ方 / Install**

zip を展開して、`Ohanami.App.exe` を起動します。インストーラーはありません。
Unzip and run `Ohanami.App.exe`. There is no installer.

- 最初の起動で、モデルのファイル(約 10.8GB)を取る画面が出ます。「ダウンロード」を押したときだけ、Hugging Face に接続します。手で置けば、一度も接続しません。
- zip には電子署名がありません。最初の起動で、Windows の SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
- スマート アプリ コントロール(Smart App Control)がオンの Windows 11 では、署名が無いため、起動できません(README の「起動で警告が出たとき」)。
- The first launch asks you to fetch the model files (about 10.8GB). The app connects to Hugging Face only when you press "ダウンロード" (Download); if you place the files by hand, it never connects.
- The zip is not code-signed, so Windows SmartScreen may show a warning on the first launch ("詳細情報" → "実行").
- On Windows 11 with Smart App Control turned on, the app cannot start because it is not signed (see the README).
